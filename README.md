# 盯盘快讯 · 浏览器扩展

一个类似「金十数据」的轻量盯盘工具：实时 A 股行情 + 7×24 金融快讯 + 财经日历。
纯浏览器直连，**无后端、无 API Key、无费用、无数据上传**。

> 开源发布 · 仅供个人学习研究 · 不构成任何投资建议（详见文末[免责声明](#免责声明)）

## 功能

- **行情页**
  - 指数实时卡片（上证 / 深成 / 创业板 / 恒指 / 纳指 / 离岸人民币 / 黄金），点击卡片弹出趋势图，支持 **1日分时 / 近7日 / 近1月 / 近半年** 周期切换（多日档为收盘价趋势折线）
  - 两市**涨跌家数**情绪条
  - 盘中**资金面**：两市成交额 + 涨停 / 炸板 / 跌停家数
  - **自选股**：搜索添加（支持代码/名称/拼音）、删除、实时刷新
  - 刷新间隔可选 5s / 15s / 30s
- **板块页**
  - 板块涨幅榜（含领涨股）
- **快讯页**
  - 7×24 滚动快讯，增量自动插入并高亮 NEW 角标
  - 过滤器：全部 / 重要 / A股 / 板块
  - 快讯关联股票标签，点击一键加入自选并跳转行情页
  - 点击条目展开摘要 + 评论数，「阅读全文」跳转东方财富原文详情
- **日历页**
  - 国外经济数据（前值 / 公布值，未公布标「待公布」）
  - 财经事件（点击展开详情与相关快讯）
  - 打新申购名单
  - 昨日 / 今日 / 明日切换，全部 / 数据 / 事件过滤，10 分钟缓存按需拉取
- **可靠性**：东财行情异常时自动降级腾讯数据源；数据源状态指示点（绿/黄/红）

## 安装（开发者模式加载）

1. 下载并解压 [Releases](../../releases) 中的 zip 包（或 clone 本仓库）
2. 打开 Chrome / Edge，进入扩展管理页：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`（选「左侧栏」下的扩展）
3. 开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择解压出的 `jin9/` 目录
5. 点击工具栏图标即可使用；快捷键 `Ctrl/Cmd+Shift+K` 呼出

> 注：popup 关闭后数据由后台 Service Worker 通过 `chrome.alarms` 定时拉取并缓存，再次打开即时可见。
> 未上架 Chrome Web Store——本工具数据来自第三方公开接口，且目标用户多在大陆（商店不可直连），开发者模式加载是当前最合适的分发方式。

## 数据源

| 用途 | 数据源 | 说明 |
|---|---|---|
| 指数 / 自选 / 板块 / 资金面 | 东方财富 `push2` / `push2ex` | `ulist.np/get`、`clist/get`、`getTopicZDFenBu` 等 |
| 股票搜索 | 东方财富 `searchapi` | `suggest/get` |
| 分时 | 东方财富 `push2his` | `trends2/get` |
| 7×24 快讯 | 东方财富 `np-listapi` | `getFastNewsList`（需带 `sortEnd`） |
| 财经日历 / 打新 | 东方财富 `datacenter-web` | `RPT_ECONOMICVALUE_*`、`RPT_CPH_FECALENDAR` 等报表 |
| 行情兜底 | 腾讯财经 `qt.gtimg.cn` | 返回 GBK，须 `TextDecoder('gbk')` 解码 |

以上均为数据源方**面向网页端的公开接口**，本扩展直接在浏览器中请求，不对数据做聚合再分发。数据版权归各数据源所有。

## 数据与存储

- **自选股 / 刷新间隔** → `chrome.storage.sync`（登录 Chrome 账号后跨设备同步；未登录自动本地化；sync 写入失败自动降级 `chrome.storage.local`，读取时兼容旧版 local 数据并自然迁移）
- **行情 / 快讯缓存** → `chrome.storage.session`（内存级，浏览器关闭即清，仅作 UI 秒开缓存）
- 全程无任何用户隐私数据上传，无埋点、无统计

## 已知限制 / 二期规划

- 快讯「下拉加载更早」为简化版（缓存上限 100 条），历史分页在二期接入
- 财经日历暂无「预期值」字段（东财报表不提供），中国数据走事件接口而非数据报表
- 二期可加：涨跌停/异动提醒、侧边栏模式（`chrome.sidePanel`）、设置持久化面板
