# 盯盘快讯 · 浏览器扩展

一个类似「金十数据」的轻量盯盘工具：实时 A 股行情 + 7×24 金融快讯。
纯浏览器直连，**无后端、无 API Key、无费用**，数据源免鉴权。

## 功能

- **行情页**
  - 三大指数实时卡片（上证 / 深成 / 创业板），点击卡片弹出**当日分时图**
  - 两市**涨跌家数**情绪条
  - **自选股**：搜索添加（支持代码/名称/拼音）、删除、实时刷新
  - **板块涨幅榜**（含领涨股）
  - 刷新间隔可选 5s / 15s / 30s
- **快讯页**
  - 7×24 滚动快讯，增量自动插入并高亮 NEW 角标
  - 过滤器：全部 / 重要 / A股 / 板块
  - 快讯关联股票标签，点击一键加入自选并跳转行情页
  - 点击条目展开摘要 + 评论数
- **可靠性**：东财行情异常时自动降级腾讯数据源；数据源状态指示点（绿/黄/红）

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」，选择本项目目录 `jin9/`
4. 点击工具栏图标即可使用

> 注：popup 关闭后数据由后台 Service Worker 通过 `chrome.alarms` 定时拉取并缓存，再次打开即时可见。

## 数据源

| 用途 | 数据源 | 说明 |
|---|---|---|
| 指数 / 自选 / 板块 | 东方财富 `push2` | `ulist.np/get`、`clist/get` |
| 涨跌家数 | 东方财富 `push2ex` | `getTopicZDFenBu` |
| 股票搜索 | 东方财富 `searchapi` | `suggest/get` |
| 分时 | 东方财富 `push2his` | `trends2/get` |
| 7×24 快讯 | 东方财富 `np-listapi` | `getFastNewsList`（需带 `sortEnd`） |
| 行情兜底 | 腾讯财经 `qt.gtimg.cn` | 返回 GBK，须 `TextDecoder('gbk')` 解码 |

**合规说明**：本扩展仅用于个人本地信息展示，不对数据做聚合再分发；数据版权归各数据源所有。请勿用于商业用途，并注意请求频率避免给源站造成压力。

## 数据与存储

- **自选股 / 刷新间隔** → `chrome.storage.sync`（登录 Chrome 账号后跨设备同步；未登录自动本地化；sync 写入失败自动降级 `chrome.storage.local`，读取时兼容旧版 local 数据并自然迁移）
- **行情 / 快讯缓存** → `chrome.storage.session`（内存级，浏览器关闭即清，仅作 UI 秒开缓存）
- 全程无任何用户隐私数据上传

## 已知限制 / 二期规划

- 快讯「下拉加载更早」为简化版（缓存上限 100 条），历史分页在二期接入
- 板块涨幅/跌幅榜切换暂固定取涨幅榜（SW 已支持 dir 参数，未接入 UI 切换逻辑）
- 二期可加：财经日历、涨跌停/异动提醒、侧边栏模式（`chrome.sidePanel`）、设置持久化面板
